Add typed, recipient-bound invitation codes with configurable formats, reviewed claims, exact-operation recovery, encrypted delivery support, and code rotation. Add paginated reads of an organization licensee's pools (`access.listOrganizationPools`) and managed invitations (`invitations.listForOrganization`), plus optional encrypted recipient display data on issuance. Managed claim rejections are limited to `expired`, `used` and `unavailable` outcomes of fully bound claims. Delivery includes reserved quantity and the immutable issued-format revision. Issuance validates returned quantity, initial version and explicitly requested expiry. Preview requires a pending reservation with finite future expiry. Claim and recovery responses retain the reviewed code version; the client rejects a response for another version. Existing caller-generated reservation tokens remain supported.

The new `invitations` client requires a service release implementing the managed invitation endpoints. Issuance and rotation require `access:write` plus `invitations:deliver`; delivery requires `invitations:deliver`; preview and claim-status reads require `access:read`; claiming requires `access:write`; format configuration uses `catalog:read` and `catalog:write`; organization pool reads require `access:read`; invitation lists require `access:read` plus `invitations:deliver`. Publishing these SDKs does not enable the service capability. Deploy the matching service before switching consumers. Minimum package and service versions must be recorded when preparing the coordinated release.
